# Sajil S Nair — Professional Portfolio

A clean, responsive personal portfolio for **Sajil S Nair**, a Computer Science and Engineering student at Reva University, expected to graduate in 2027.

The portfolio is intentionally designed as a professional extension of the resume: minimal visual effects, restrained color, clear technical sections, and direct links to verified project repositories.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Inter (Google Fonts)

No framework or build step is required.
